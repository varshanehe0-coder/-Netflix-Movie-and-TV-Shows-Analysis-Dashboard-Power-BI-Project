📌 Project Overview

The Netflix Content Analysis Dashboard is an interactive data visualization project developed using Microsoft Power BI. This project analyzes Netflix movies and TV shows to identify content trends, distribution patterns, and insights across different countries, genres, ratings, and release years.

🎯 Project Objective

The main objective of this project is to explore Netflix's content library and transform raw data into meaningful visual insights that support better understanding of content distribution and trends.

🛠️ Tools & Technologies

- Microsoft Power BI – Dashboard development and data visualization

📊 Key Dashboard Features

- Content Overview: Analysis of total titles, movies, and TV shows.
- Content Type Analysis: Comparison of movies and TV shows.
- Genre Analysis: Exploration of popular genres and categories.
- Country Analysis: Visualization of content distribution by country.
- Ratings Analysis: Understanding the distribution of content ratings.
- Release Year Trends: Analysis of content across different release years.
- Interactive Dashboard: Filters and visuals for exploring the data.

📈 Key Insights

- Comparison of movies and TV shows in the Netflix content library.
- Identification of major content-producing countries.
- Exploration of popular genres and content ratings.
- Understanding of content release trends over time.
